# Faraday-lab

전자기 유도 짝 탐구 시뮬레이터입니다. 한 기기를 2~3명이 함께 사용하며 개인 활동지에 기록합니다.

## 활동 흐름
과학사 → 첫 가설과 까닭 → 조건 예측·비교 계획 → 자석 세 조건 가상 관찰 → 실제 여섯 조건·빠르기 비교 → 처음 가설 판단 → 패러데이와 과학의 본성.

가상실험 뒤에는 관찰만 기록합니다. 가설 수정은 실제 실험을 마친 뒤 증거를 비교하며 합니다. A/B/C는 활동지 2쪽, D/E는 3쪽, F/G는 4쪽입니다. 빠르기 비교는 같은 구간에서 자석을 느리게/빠르게 넣을 때 최대 바늘 흔들림을 비교합니다.

## 실험 후 읽기 자료
전원이 F에 판단과 근거를 기록했다고 확인하면 마무리 화면에 **패러데이와 과학의 본성 읽기** 버튼이 나타납니다. 성실한 배움 → 앞선 발견에서 새 질문으로 → 모두를 위한 과학의 세 이야기를 교사와 약 3분 동안 함께 읽고, 자세한 내용은 같은 순서로 펼쳐 읽습니다. 첫 가설·예측·실험 중에는 해설이 표시되지 않습니다. 내용은 교재 발췌와 역사 자료를 요약·재구성했으며 자료 안에 출처를 적었습니다.

## 단계 이동
상단의 이전·다음 버튼으로 이동합니다. 완료한 종이 기록 확인은 유지됩니다. 아직 관찰·기록을 마치지 않은 단계에서는 다음으로 갈 수 없습니다. 이전 관찰로 돌아와도 결과는 자동 재생하지 않습니다. 다시 보기를 시작하면 그 조건을 새로 관찰하고 기록 확인합니다. 새로 고침하면 처음부터 시작합니다.

## 실행
index.html을 브라우저에서 엽니다. 모든 폴더를 함께 보관합니다. 외부 API·로그인·학생 답안 전송을 사용하지 않습니다.

## 화면 크기와 조작
휴대폰과 태블릿의 좁은 화면에서는 장치 그림 아래에 실험 안내가 이어집니다. 자석 설명과 관찰 상태는 그림과 분리해 표시하며, 글·표·확인란은 화면 폭에 맞게 줄바꿈됩니다. 관찰하기를 누르면 장치와 검류계가 있는 곳으로 이동합니다. 화면을 돌려도 진행 중인 기록 확인을 유지합니다. 손가락 화면 확대는 제한하지 않으며, 장치를 끌기 어려울 때에는 관찰하기 버튼을 사용합니다.

노트북 1366×768, 태블릿 가로 1280×800의 두 열 배치는 유지합니다. 휴대폰 검증은 브라우저의 화면 크기·터치 모의 환경을 사용하므로 실제 기기의 Safari·카카오톡 내장 브라우저에서도 수업 전에 확인합니다.

## GitHub Pages 최초 설정
저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
배포가 끝나면 같은 화면의 Visit site에서 학생용 주소를 확인합니다.

## 이후 수정과 게시
이 Faraday-lab 폴더가 앞으로의 수정 기준입니다.
1. 수정한 화면을 확인합니다. TypeScript를 수정했다면 scripts/의 JavaScript도 함께 빌드합니다.
2. GitHub Desktop에서 Faraday-lab을 선택하고 변경 내용을 확인합니다.
3. 변경 설명을 적고 Commit to main을 누릅니다.
4. Push origin을 누르면 GitHub Pages가 갱신됩니다.

컴퓨터의 파일 저장만으로 온라인 사이트가 바뀌지는 않습니다. Commit은 컴퓨터에 기록하고, Push가 GitHub로 올리는 단계입니다.
